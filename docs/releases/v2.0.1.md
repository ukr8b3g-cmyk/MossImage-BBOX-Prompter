# MOSS BBOX Prompter 2.0.1

This update protects saved prompts during automatic reference-image analysis.

- If you change the reference image, target, box coordinates, prompt, Type, or analysis switch while analysis is running, the old result cannot overwrite the current card. An in-flight generation can still finish with its queued inputs.
- Image analysis accepts Character and Object targets. Text boxes keep their dialogue and lettering.
- Turning analysis OFF keeps the last saved text so you can edit it and generate with the edited prompt.
- Layout import rejects an explicitly blank Type. Older layouts with an omitted Type or `obj` still work.

Update the custom node, restart ComfyUI and reload the browser. The V2 workflow and existing saved layouts remain compatible. The attached workflow ZIP contains the V2 template, reference image and guides.

## 日本語

- 解析中に参照画像・対象・座標・本文・Type・解析スイッチを変更すると、旧結果が現在の本文を上書きしません。実行中の生成は、キュー登録時の入力で完了することがあります。
