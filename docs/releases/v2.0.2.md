# MOSS BBOX Prompter v2.0.2

Large workflows are more responsive when using Canvas or Prompter. Unconnected Prompters skip graph searches, connected cards reuse subgraph lookups, and unchanged values no longer request another full-workflow snapshot.

- Tested in ComfyUI with Canvas and Prompter separately in a large workflow, including alongside Krea2.
- Verified workflow save and reload, GPU generation, and protection against stale reference-image analysis results.
- If you use both extensions, update [Krea2 BBOX Prompter to v1.0.4](https://github.com/ukr8b3g-cmyk/Krea2-BBOX-Prompter/releases/tag/v1.0.4) for the companion fix.
- The V2 workflow ZIP contains the existing template, reference image and guides.
