## MOSS BBOX Prompter 1.0.11

### English

- Uniform compact controls before and after connection: four fixed rows, consistent typography and a 170px starting height across all seven colors. Saved manual sizes remain intact.
- Name and Shared actions are under the header **⋯**. Shared color cards use the same menu position for presets. Selecting boxes does not fold cards or switch editing views.
- Fix prompt/Type ownership, workflow restoration and saved field heights so stale property mirrors do not replace current input. Shared-value replacement still requires confirmation and previews its text.
- Add Rear 3/4 left/right and Voyeur low angle, plus independent Focus (including Breasts and Crotch). Text keeps unused framing/angle/focus controls in place, disabled.
- Expand Text dialogue controls to 7 usages and 22 shapes, with structure, writing direction, colors and an offline emoji picker. Appearance controls preserve literal wording.
- Include updated English/Japanese README guides, Krea2 effect wiring instructions and three workflow JSON downloads. The current template retains example words and generation settings; newly created nodes start with empty prompts.

**Update:** save your workflow, finish running work, update the package, restart ComfyUI normally and press Ctrl+F5. Upgrading from 1.0.10 or earlier changes Python inputs for Focus. Existing node IDs, socket types, positional widgets and saved workflows remain supported. External text-input improvements remain deferred. Krea2 and JP Assist are separate optional extensions; this release does not update them.

**Validation:** JavaScript 117 checks; Python CPU suite and workflow-output compatibility; isolated real-ComfyUI checks for all seven colors, connection states, Type changes, English/Japanese, menus and manual-size restoration. Template/Standard/DMD CPU exports match the pre-UI-change versions. No new GPU generation was run during publication.
