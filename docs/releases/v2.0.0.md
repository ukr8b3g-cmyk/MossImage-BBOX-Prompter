# MOSS BBOX Prompter 2.0.0

V2 adds reference-image analysis to the supplied Canvas workflow while retaining V1 node IDs and saved-workflow compatibility.

- Load the included reference image, select a target and kind, enable **Image analysis enable**, then Run. Analysis text is saved automatically to the target card and used for generation.
- Switch analysis OFF to keep and edit that text, or replace it with a different prompt. Normal generation then uses the saved body. Running again with analysis ON overwrites the body with the new analysis.
- Auto selects the first created/stored box and displays its resolved color. Explicit box IDs stay fixed. Missing box with analysis ON is an error; select an existing box or create one first.
- System prompt, max_length, Sampling Mode, thinking, use_default_template and MTP are visible and saved. Sampling details reuse Core Generate Text controls.
- The scope is one reference image and one target box. New nodes start with blank prompts. Existing manual text, Type, styles and editor sizes retain their existing owners.

Use a MOSS-capable ComfyUI with Core Generate Text / If/Else Switch / Seed, and install rgthree-comfy for the template's Power Lora Loader. Select your installed model/TE/VAE/LoRA files. Save your work, restart ComfyUI normally, then refresh the browser with Ctrl+F5.

The user confirmed GPU operation of the supplied V2 workflow. Developer checks cover CPU compatibility, native UI, parameter forwarding, save/reload and packaging; these are separate from GPU image-quality claims. Registry publication is separate from this GitHub Release.

## 日本語

参照画像を読み込み、Image analysis enableをtrueにして実行すると、指定枠の解析文をカードへ自動保存して画像生成に使います。falseにすると文章が残り、そのまま編集・別の文章への変更・従来どおりの生成ができます。再びtrueで実行すると、編集した本文も新しい解析文で上書きされます。

Autoは最初の枠を使い、明示指定は既存の枠IDを保持します。Missing boxのまま解析ONで実行するとエラーになります。今回の解析範囲は画像1枚・対象枠1つです。システムプロンプトとCoreの解析パラメータを表示し、V1の既存ノード・保存設定との互換性を維持しています。

配布案内はV2と前版V1の2系統です。添付テンプレートの本文・設定・ノード名は保持しています。GPU動作はユーザー確認済みで、開発側のCPU・画面・保存復元の検証とは区別します。
